Projects

Shortest Path Between Doctors and Patients

A Python group project finding efficient routes between doctors and patients (the travelling salesman problem). The program uses local search and the Great Deluge algorithm to iteratively improve randomly generated routes while considering constraints on the number of patients assigned to each doctor.

The project also uses GPS data and the Haversine formula to apply the algorithms to real-world geographical locations. We used NetworkX and matplotlib to visualise routes and analyse the convergence and performance of the optimisation algorithms.

Generating Text Using Random Processes

A Python group investigating the use of mutation and genetic algorithms for optimisation. The code generates random strings and uses iterative mutation and selection to evolve them towards a specified target string, with experiments investigating the effects of mutation rates and population size.

The project was extended to show how similar evolutionary techniques can be applied to the shortest-path problem, using genetic algorithms to find efficient routes through a set of points.

beanPy – A Statistical Distribution Sampling Library

beanPy is a Python library developed as part of a group programming project for generating random samples from a range of statistical distributions. The library contains the normal, exponential, Poisson, and continuous and discrete uniform distributions, and allows users to input distribution parameters and random seeds.

The library can also be used to generate probability density and cumulative distribution plots using matplotlib. As an example, we used beanPy to model the throws of a darts player using independent normal distributions to represent their horizontal and vertical accuracy.
